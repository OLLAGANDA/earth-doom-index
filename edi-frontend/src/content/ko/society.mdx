# 사회 위협 지수란?

본 페이지는 준비 중입니다.

이 지수는 **GDELT(Global Database of Events, Language, and Tone)** 뉴스 이벤트 데이터를 기반으로 전 세계 시위·분쟁·무력 충돌의 빈도와 강도를 0~30점으로 환산한 지표입니다. CAMEO 코드 분류를 활용해 사건 유형별로 가중치를 적용하고, NumMentions(언론 노출량)으로 강도를 보정합니다.

상세 설명은 곧 공개됩니다.
